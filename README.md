# What's In My Fridge – Smart Food Management App

## Overview

What's In My Fridge is a mobile application designed to help users manage the food items they currently have at home.

The goal of the project is to demonstrate application design, data management, and user-focused functionality.

---

## Features

* Manage food items stored in the fridge
* Track product quantities
* Improve organization of groceries
* User-friendly interface

---

## Concept

The application helps reduce food waste by allowing users to track what they currently have in their fridge and manage their food inventory more efficiently.
